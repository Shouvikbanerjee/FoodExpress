# 🍔 FoodExpress – Online Food Ordering & Delivery Platform

## 📌 Overview

**FoodExpress** is an online food ordering and delivery platform designed to connect customers with restaurants and delivery partners through a unified digital system.

It allows users to:

* Browse restaurants and their menus
* Place and manage orders
* Make cash payments
* Track deliveries in real time

FoodExpress aims to provide a **fast, reliable, and user-friendly experience** for all stakeholders—customers, restaurants, and delivery personnel—while maintaining high standards of service and convenience.

## 📦 Modules

### 👤 1. User Module

* User registration and login (with basic OTP verification)
* Browse restaurants and menus
* Place and cancel orders
* Track order status
* Manage profile and order history



### 🍽️ 2. Restaurant Module

* Restaurant registration and login (with basic OTP verification)
* Manage menu items (Add, Edit, Delete)
* View and process incoming orders
* Update order status (Accepted, Cancelled, Out for Delivery)
* Manage restaurant details



### 🚚 3. Delivery Partner Module

* Delivery partner registration and login (with basic OTP verification)
* Accept or cancel delivery assignments
* Pick up and deliver orders
* Update delivery status and complete orders
* View all orders and payments
* Manage profile details



### 🛡️ 4. Admin Module

* Admin login (with basic OTP verification)
* Manage admin details
* Manage users, restaurants, and delivery partners
* Monitor orders and transactions



## ⚙️ Key Features

* 🔐 OTP-based authentication system
* 📦 Order management system
* 📍 Real-time order tracking (planned/enhanced)
* 💵 Cash on Delivery support
* 📊 Multi-role system (User, Restaurant, Delivery, Admin)
